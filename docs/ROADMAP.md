Справочник валют, журнал транзакций, балансы, выбор разрешённых валют для сервисов, начисления по ролям из настроек.

Шаблоны заданий, выполнение пользователем, проверка, повторяемость, награды.

Товары, категории, заказы и статусы, оплата внутренней валютой.

## Этап 6. Обучение и тесты — ⏳
Курсы, назначения группам, тесты, база знаний.

Внутренний чат (участие через группы), уведомления, админские настройки, редактор визуальной части.
