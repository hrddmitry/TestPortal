# WORKFLOW

Этот документ описывает предпочтительный формат работы над TestPortal.
Его нужно читать в начале нового чата, чтобы продолжить работу в том же стиле.

## Принципы работы

- Работать небольшими завершёнными шагами: один этап — один проверяемый результат.
- Не предполагать, что предыдущая команда уже выполнена: сначала уточнить состояние или дать команду проверки.
- Давать команды PowerShell блоками, которые можно скопировать и выполнить целиком.
- После каждого блока просить пользователя прислать вывод.
- Исправлять только подтверждённые ошибки по точному traceback или выводу.
- Перед запуском сервера проверять импорты командой `uv run python -c "import backend.main; print('IMPORTS OK')"`.
- Не отправлять секреты, пароли и содержимое `.env` в чат или Git.
- Коммитить только проверенное рабочее состояние.
- После успешной проверки добавлять запись в `docs/LOG.md` и отправлять изменения в GitHub.

## Среда

- ОС: Windows.
- Терминал: PowerShell.
- Репозиторий: `C:\Users\PC\Projects\TestPortal`.
- Backend: `backend`.
- Python-окружение: `uv`.
- База данных: PostgreSQL через Docker Compose.
- Backend-запуск: `uv run uvicorn backend.main:app --reload` из каталога `backend`.
- Сервер: `http://127.0.0.1:8000`.
- Проверка здоровья: `GET /api/health`.

## Формат ответа ассистента

1. Кратко сказать, что будет сделано.
2. Дать один цельный блок PowerShell.
3. Объяснить, что именно произойдёт.
4. Попросить прислать вывод.
5. После успеха — предложить следующий шаг.
6. После завершённого этапа — дать команды `git add`, `git commit`, `git push` и обновление `docs/LOG.md`.

## Проверки перед продолжением

Перед созданием или изменением кода:

- Проверять существующую структуру проекта, если путь не подтверждён.
- Проверять импорты до запуска uvicorn.
- После изменений моделей создавать и применять Alembic-миграцию.
- После API-изменений проверять запросы через `Invoke-RestMethod`.
- После успешной проверки коммитить изменения.

## Текущее состояние проекта

- Backend: FastAPI, SQLAlchemy, Alembic, PostgreSQL.
- Модуль `users`: создание, список, получение пользователя, установка пароля.
- Модуль `auth`: bcrypt-хеширование, JWT, `POST /api/auth/login`, `GET /api/auth/me`.
- Модуль `roles`: `Role`, `Permission`, связи `role_permissions`, `user_roles`, `user_permissions`.
- API ролей и прав: создание, просмотр, назначение права роли, роли пользователю и права пользователю.
- Тестовый пользователь: id 1, `test@example.com`, роль `Administrator`, право `users.manage`.
- Следующий шаг: проверка прав при доступе к защищённым эндпоинтам.

## Важные решения

- Пользователи создаются администратором; саморегистрация и приглашения на старте не нужны.
- Email хранится в нижнем регистре и уникален, включая мягко удалённых пользователей.
- Мягкое удаление пользователя — через `deleted_at`.
- Права — только «можно/нельзя»; уровни назначения: роль и пользователь.
- Группы могут включать людей вручную и формироваться по отделам/должностям.
- Состав группы в чатах — отдельная логика модуля `chat`, реализуется позже.
- Баллы и валюта не входят в модуль `users`; их реализация отложена.

## Подтверждённая структура

- Корень: `backend`, `frontend`, `docs`, `compose.yaml`, `.env`, `.env.example`.
- Backend-код: `backend\src\backend`.
- Конфигурация: `backend\src\backend\config.py`.
- Точка входа: `backend\src\backend\main.py`.

- Функциональные модули: `backend\src\backend\modules\auth`, `backend\src\backend\modules\roles`, `backend\src\backend\modules\users`.
- Миграции: `backend\migrations\versions`.
- Frontend: `frontend`, стандартный каркас Vite + React + TypeScript.
- Пустой каталог `backend\app` удалён как артефакт первоначального каркаса.
- Цепочка миграций линейна; текущая ревизия — `5947759fb2ef`.
## Соглашение по базе данных

- Все таблицы и все поля получают русские комментарии в БД: `comment="..."` у колонок и `__table_args__ = {"comment": "..."}` у таблиц.
- Коды прав (например, `groups.manage`) остаются латиницей, потому что по ним работает код; название и описание права пишутся по-русски.
- Правило действует для всех новых моделей и миграций.
